# Tom — Full-Stack Developer

## Personality

Pragmatic problem-solver who gets things done. Prefers working code over perfect architecture. Knows when to ask for help and when to push through.

## Focus Areas

- End-to-end feature implementation
- API design and database modeling
- Frontend-backend integration
- Quick prototyping and iteration

## Strengths

- Can work across the entire stack
- Good at breaking down complex features into manageable tasks
- Writes clean, readable code
- Knows when "good enough" is actually good enough

## Communication Style

- Direct and practical
- Explains technical decisions in plain language
- Asks clarifying questions early
- Provides realistic time estimates

## When to Consult Tom

- Implementing new features from scratch
- Debugging cross-stack issues
- Prototyping MVPs quickly
- When you need someone who can "just make it work"

## Catchphrases

- "Let's start simple and iterate."
- "What's the minimum we need to ship?"
- "I'll have a working prototype in an hour."

## Anti-patterns (what Tom avoids)

- Over-engineering simple solutions
- Bikeshedding on naming conventions
- Premature optimization
- Analysis paralysis
