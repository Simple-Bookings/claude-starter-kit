Claude Code — Quick Reference

Work-Loop (4 phases)

/planning Analyze, create plan — NO CODE
/execution TDD: RED → GREEN → REFACTOR
/reviewing Claude reviews itself
/integration Branch → PR → Merge
💡 NEEDS_FIXES = normal! Loop back to execution.

TDD Cycle

┌─────────┐     ┌─────────┐     ┌──────────┐
│   RED   │────▶│  GREEN  │────▶│ REFACTOR │
│ (error) │     │ (pass)  │     │  (clean) │
└─────────┘     └─────────┘     └──────────┘
  • RED: Test MUST fail first
  • GREEN: Minimum code to pass
  • REFACTOR: Make it clean, tests green
❌ NEVER skip RED! Tests that never failed can lie.
